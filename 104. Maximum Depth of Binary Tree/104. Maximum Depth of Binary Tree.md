最初に思いつくのは深さ優先探索
全部見るから計算量的にはO N
空間は　最大Nかいスタックに積まれるからO　N
スタック・オーバーフローが怖い　最大でも今回は10^4程度の呼び出しになる
Pythonは通常だと１０００回がマックスなのでスタックを実装したほうがよさそう
一応スタックなしバージョンを提出
通る
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pass_node(self,node: Optional[TreeNode], depth: int) -> int:
        if not node:
            return depth

        left_depth = self.pass_node(node.left, depth + 1)
        right_depth = self.pass_node(node.right, depth + 1)
        return max(left_depth, right_depth)
    def maxDepth(self, root: Optional[TreeNode]) -> int:

        if not root:
            return 0
        return self.pass_node(root, 0)
```

Stack バージョン
pass_nodeではこれから通るという意味でrootのときは0にしていたけど
こっちでは0だとわかりにくくなると感じたので1にしている
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        stack = [(root, 1)]
        max_depth = 0
        while stack:
            node,depth = stack.pop()
            if not node:
                max_depth = max(max_depth,depth-1)
            else:
                stack.append((node.left, depth + 1))
                stack.append((node.right, depth + 1))
        return max_depth
```
