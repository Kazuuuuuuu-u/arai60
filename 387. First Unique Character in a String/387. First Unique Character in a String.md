387. First Unique Character in a String
Step1
問題文の理解
文字列が与えられてその中に見つかる最初の重複しない文字のインデックスを返す。
見つからなかったら−１
制約　文字列の長さは10^5まで
小文字のアルファベットのみ

思いつく方法
他の文字でも対応できるようにしたいからアルファベット特有のものは使いたくない

インデックスと文字の辞書にして、ソートする。同じ文字が続く限りスキップしていく
最終的にインデックスの最小値を求める
時間　N 空間N

ユニークかどうかだからsetを使いたい
思いつくのは二つのセットを使う方法
重複と重複しない奴らをわける

Setの戦闘取り出しできないから複雑になる


あとは辞書で文字と文字の出現回数を数えて、もう一度ループがいいか
これが一番シンプル
N　N
一番最初にでてくるべきなのにこの解法全然出てこんかった


```python
from collections import defaultdict


class Solution:
    def firstUniqChar(self, s: str) -> int:

        character_to_count = defaultdict(int)

        for character in s:
            character_to_count[character] += 1

        for index, character in enumerate(s):
            if character_to_count[character] == 1:
                return index

        return -1

```
