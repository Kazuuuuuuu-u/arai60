49. Group Anagrams

問題文の理解

ぱっと思いつくのはハッシュ化すれば同じ構成要素は同じ値になるのではないか
それを辞書にしてリスト化する。
時間 N 空間　N
他の方法は？
その文字列が辞書の中にあるかないか調べてあるなら代表値と要素を比較して調べる方法

空間 N

シンプルなのはハッシュ

defaultdictを使うともっとシンプル
```python
from collections import defaultdict


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:

        representative_value_to_anagrams = defaultdict(list)

        for string in strs:
            sorted_string = "".join(sorted(string))
            representative_value_to_anagrams[sorted_string].append(string)

        return list(representative_value_to_anagrams.values())
```
