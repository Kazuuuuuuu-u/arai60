

Step1
問題文は
ローカル@ドメイン名という構造が有効
よって、ローカルがない場合、ドメイン名がない場合、@がない場合、@が複数ある場合を無効
区切りは@で行われて、小文字と.、+が有効文字

特定の文字には効果がある。
.なら無視できる
+ならそれ以降無視
ドメイン名はそれらの効果を受け付けない
ただしドメイン名は.comで終わる必要あり
よって、それ以外の文字が入っていた場合も無効

出力が個数なので、リストとかの形で実際に異なるメールアドレスを持っておいて、その個数を調べるという方法が一つ

その場合、重複を排除することになるのでsetやdictionaryを用いるのが楽
Keyがなくても個数はわかるのでsetがいいか
リストでもできるけど結局メモリ的には変わらなさそうだし探索の時間がかかる

コレを拡張するとなると、特定の文字の禁止や許可がかんがえられるのでそこをまとめとく書き方がいいか

それ以外だとなにかあるか
時間計算は、リストの個数をN、各文字列をM、有効文字をSとするとN*M*S　空間はN+M+S

```python
import string
import io


class Solution:
    def numUniqueEmails(self, emails: List[str]) -> int:
        valid_characters = [".", "+", *string.ascii_lowercase]
        dot_com = ".com"
        valid_emails = set()

        for email in emails:
            email_component = email.split("@")
            if (
                not len(email_component) == 2
                or (not self.is_valid_character(email_component[0], valid_characters))
                or (
                    not self.is_valid_character(email_component[1], valid_characters)
                    and not dot_com == email_component[1][-4:]
                )
            ):
                continue

            actual_local_string_buffer = io.StringIO()

            for character in email_component[0]:

                if character == ".":
                    continue
                elif character == "+":
                    break
                actual_local_string_buffer.write(character)
            actual_local_string = actual_local_string_buffer.getvalue()
            email_component[0] = actual_local_string
            valid_emails.add("@".join(email_component))

        return len(valid_emails)

    def is_valid_character(self, email, valid_characters):
        for character in email:
            if not character in valid_characters:
                return False

        return True
```

```python
class Solution:
    def numUniqueEmails(self, emails: List[str]) -> int:
        valid_emails = set()

        for email in emails:
            email_component = email.split("@")
```

```python
            actual_local_string_list = []

            for character in email_component[0]:

                if character == ".":
                    continue
                elif character == "+":
                    break
                actual_local_string_list.append(character)
            actual_local_string = ''.join(actual_local_string_list)
            email_component[0] = actual_local_string
            valid_emails.add("@".join(email_component))

        return len(valid_emails)
```
